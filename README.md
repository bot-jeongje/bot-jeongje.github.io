# 변정제 · Embedded Systems Portfolio
링크 : https://bot-jeongje.github.io/
회로 설계부터 펌웨어와 디버깅까지의 개발 경험을 소개하는 정적 포트폴리오입니다.

## 구성

- 핵심 역량: 하드웨어 설계, MCU·RTOS, 계측 기반 디버깅
- 경력: 쿠첸 인덕션 Control 펌웨어, LIG넥스원 항공 시스템
- 프로젝트: 모듈형 로봇, STM32 무선 RC카, ROS 2 Smart Plant, 국제 캡스톤, Mitsubishi PLC 제어
- 프로젝트별 문제 해결 상세, 분류 필터, 모바일 레이아웃, 인쇄 기능

## 실행 및 게시

별도 설치나 빌드가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.
GitHub Pages에서는 `main` 브랜치의 `/ (root)`를 게시 소스로 선택합니다.
프로젝트 사진, 영상 포스터, 30초 시연 영상은 모두 HTML에 포함되어 있어 `index.html` 한 파일로 동작합니다. 원본 영상의 00:45–00:55, 02:20–02:30, 03:15–03:25 구간을 무음으로 편집했습니다.
