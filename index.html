01 / COMMUNICATION

통신 오버플로우 해결

문제 1ms 주기의 데이터 전송에서 블루투스 통신 오버플로우가 발생했습니다.

해결 트래픽과 프로토콜 길이를 분석하고 전송 주기를 100ms로 조정해 제어 명령 송수신을 안정화했습니다.

02 / POWER INTEGRITY

해결 전원 회로에 커패시터를 추가해 전원 안정성을 보완하고 다족 로봇의 움직임을 구현했습니다.

03 / ARCHITECTURE

모듈 자동 인식과 주기별 제어

구현 UART Ping으로 모듈 연결 상태와 방향을 인식하고, 블록 조합에 따라 기능을 구성했습니다.

구조 1ms 타이머를 기준으로 50·100·250·500·1000ms 작업을 분리한 Bare-metal 스케줄링을 설계했습니다.

01 / FAIL-SAFE

유효 패킷을 기준으로 제어

Circular Queue 기반 파서로 프레임을 추출하고, 500ms 이상 정상 패킷을 수신하지 못하면 비상 정지 상태로 전환했습니다. 모터의 미세 떨림은 Deadband 처리로 억제했습니다.

02 / RENDERING

변경 영역만 갱신하는 LCD

Dirty-Rectangle 방식으로 캐릭터 이동에 따라 바뀐 영역만 갱신해 화면 깜빡임을 줄였습니다. 1ms 타이머를 기준으로 제어 10ms, 통신·IMU·LCD 50ms, 초음파 100ms 작업을 분리했습니다.

03 / HARDWARE DEBUG

01 / HOST & HARDWARE

Host 환경 구성과 회로 설계

Raspberry Pi 5에 Ubuntu 24.04와 ROS 2 Jazzy 환경을 구성하고 패키지 의존성 문제를 해결했습니다. Topic·Action·Service 통신 구조를 적용하고, 로봇과 Host 간 통신을 구성했습니다.

02 / COMMAND & RESULT

작업 요청부터 결과 반환까지

Waffle Action 서버는 Host 명령을 받아 로봇 작업으로 연결합니다. 작업 중 중복 요청과 빈 명령을 거절하고, 작업이 끝나면 성공 여부와 결과 메시지를 반환하도록 구성했습니다.

장치별 명령과 Goal·Feedback·Result 필드를 정리한 공통 프로토콜을 기준으로 연동했습니다.

03 / ROBOT CONTROL
